# UI Kit — Tienda Lucas Innovaciones

Recreación click-thru de la tienda online. Homepage → PDP → Checkout, con componentes reusables que se pueden portar a un theme de WooCommerce.

## Archivos
- `index.html` — demo interactivo (navega entre home/PDP/checkout).
- `Header.jsx` — topbar con buscador + carrito + WhatsApp.
- `Footer.jsx` — footer completo con contacto, info, métodos de pago.
- `ProductCard.jsx` — card de producto para grids y carousel.
- `Home.jsx` — armado completo de la homepage.
- `Product.jsx` — página de detalle.
- `Checkout.jsx` — checkout de 3 pasos en 1 columna.
- `Primitives.jsx` — Button, Badge, Input, Icon, Price, WhatsappFab.

## Cobertura
- Hero con tagline + CTA + producto destacado
- Tira de marcas
- Grid de categorías (6)
- "Lo más vendido" carousel
- Sección de confianza (local + reseñas)
- Banner "12 cuotas sin interés"
- WhatsApp flotante verde
- PDP: galería, precio + cuotas, garantía, specs en acordeón, relacionados
- Checkout: envío vs retiro, Mercado Pago / transferencia / efectivo, resumen sticky

## Qué NO incluye
- Catálogo completo / listado con filtros (fuera del alcance del brief).
- Login / cuenta del cliente.
- Blog / CMS.

Se puede sumar en una segunda iteración si el cliente lo necesita.
